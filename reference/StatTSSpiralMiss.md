# Statistical Transformation for Spiral Missingness

Internal statistical transformation used by
[`geom_tsspiralmiss()`](https://thiyangt.github.io/tsspiral/reference/geom_tsspiralmiss.md).

## Usage

``` r
StatTSSpiralMiss
```

## Format

An object of class `StatTSSpiralMiss` (inherits from `Stat`, `ggproto`,
`gg`) of length 3.
